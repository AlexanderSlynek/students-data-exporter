# Student Data Exporter

An interactive Command Line Interface (CLI) application written in Python. It allows users to input student names and their grades, and then export the collected data into popular file formats (TXT, CSV, or JSON).

## Features

* Interactive Menu: Simple and user-friendly CLI loop.
* Multiple Export Formats: Save your data as Plain Text (.txt), Comma-Separated Values (.csv), or JavaScript Object Notation (.json).
* Error Handling: Robust input validation with try-except blocks to prevent crashes on invalid inputs.

## Tech Stack

* Python 3 (uses built-in json module, no external dependencies required)

## Installation & Running

1. Clone the repository:
git clone [https://github.com/AlexanderSlynek/students-data-exporter.git](https://www.google.com/search?q=https://github.com/AlexanderSlynek/students-data-exporter.git)
2. Navigate to the project directory:
cd students-data-exporter
3. Run the application:
python main.py

## How to Use

1. Launch the program and choose an option from the menu:
* 1 - Export to TXT
* 2 - Export to CSV
* 3 - Export to JSON
* 4 - Exit


2. Follow the interactive prompts to enter the number of students, their names, and grades.
3. Type the desired filename, and your file will be created instantly!
